# Install FREQ Home 0.3.0

Install the signed 0.3.0 APK over the existing FREQ app. Do not uninstall first: uninstalling removes local notes, tasks and preferences. The package remains dev.farhan.freq and the signing identity matches the earlier prototype.

Open FREQ → OPEN LIVE GRID. Sign in with ChatGPT if asked. GRAPH opens the current Knowledge Graph; AREA TREE opens and pins the Area → projects → tasks tree. Use the site's touch edit toggle for hierarchy moves. Notion authentication and actual edits require testing on the phone.

The center APPS button opens installed Android apps. LOCAL returns to the offline launcher. System Lab → Open live workspace on Home chooses the landing screen. Android Home settings still choose the default launcher.

If the embedded sign-in does not complete, use the live view menu → Open in browser. This opens the connected site with the browser's own session; it does not sign in the embedded view.

No root is needed. Notification-reading declarations remain removed. Installation acceptance is not guaranteed: if Play Protect still hard-blocks it, preserve the exact warning for investigation rather than changing security settings.
